# How to make a submission

Fork this repo first. The [README](../README.md) lists the required files, local
validation command, and pull request steps.

Choose a benchmark and follow its guide for evaluation rules and checkpoint
format:

- [Snake](how-to-make-a-snake-submission.md)
- [Image compression](how-to-make-an-image-compression-submission.md)
- [Chess](how-to-make-a-chess-submission.md)
- [Control](how-to-make-a-control-submission.md)

The leaderboard takes the submission date from the Git commit that first adds
`config.json`.
